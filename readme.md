# Jeu Feu / Eau / Terre

Petit jeu en JavaScript : le joueur affronte l'ordinateur avec trois pouvoirs.

### Règles
- Feu bat Terre  
- Eau bat Feu  
- Terre bat Eau  
- Égalité si les deux choix sont identiques  

### Technologies
- **HTML5** : structure de la page  
- **CSS3** : style et mise en forme  
- **JavaScript (ES6)** : logique du jeu et manipulation du DOM  

### Choix techniques
- Fichier `script.js` : logique pure du jeu  
- Fichier `dom.js` : gestion des événements et du DOM  
- Scores et bouton "Rejouer" ajoutés pour une expérience complète
